## Claude Code Hook Payload Format (researched)

HTTP hooks receive POST with JSON body:

```ts
// PreToolUse
{
  session_id: string          // unique per Claude Code process
  hook_event_name: "PreToolUse"
  tool_name: string           // "Bash" | "Edit" | "Write" | "Read" | "Glob" | "Grep" | "Agent" | ...
  tool_input: Record<string, unknown>
  tool_use_id: string         // correlates PreToolUse and PostToolUse for same call
}

// PostToolUse
{
  session_id: string
  hook_event_name: "PostToolUse"
  tool_name: string
  tool_input: Record<string, unknown>
  tool_response: unknown      // varies by tool
  tool_use_id: string
}

// Notification
{
  session_id: string
  hook_event_name: "Notification"
  message: string
}

// Stop | SubagentStop
{
  session_id: string
  hook_event_name: "Stop" | "SubagentStop"
}
```

HTTP hooks: Claude Code sends POST to configured URL. Non-2xx → non-blocking error (execution continues). Return `{ decision: "block" }` to block; omit or `{ decision: "allow" }` to allow.

## SSE Pattern for Next.js 16 App Router

Use `ReadableStream` with Web Streams API — works natively in Next.js 16:

```ts
export async function GET(request: Request) {
  const encoder = new TextEncoder()
  const stream = new ReadableStream({
    start(controller) {
      const listener = (event: ClaudeEvent) => {
        controller.enqueue(encoder.encode(`data: ${JSON.stringify(event)}\n\n`))
      }
      eventBus.on('event', listener)
      request.signal.addEventListener('abort', () => {
        eventBus.off('event', listener)
        controller.close()
      })
    }
  })
  return new Response(stream, {
    headers: {
      'Content-Type': 'text/event-stream',
      'Cache-Control': 'no-cache, no-transform',
      'Connection': 'keep-alive',
      'X-Accel-Buffering': 'no',
    }
  })
}
```

## Global Singleton Pattern (survives Next.js HMR)

```ts
declare global {
  var __eventBus: EventEmitter | undefined
  var __events: ClaudeEvent[] | undefined
}
export const eventBus = globalThis.__eventBus ??= new EventEmitter()
export const events = globalThis.__events ??= []
```

## AC-2: SSE endpoint streams events to browser
```gherkin
Given a browser client is connected to /api/events
When a new event arrives on the event bus
Then the client receives it as an SSE message within 100ms
And the connection stays open for subsequent events
```

## AC-3: Ring buffer limits memory
```gherkin
Given the ring buffer is at capacity (500 events)
When a new event arrives
Then the oldest event is dropped
And the buffer stays at 500 events
```

## AC-4: SSE replays recent events on connect
```gherkin
Given the ring buffer has existing events
When a new browser client connects to /api/events
Then it immediately receives all buffered events before live streaming begins
```
