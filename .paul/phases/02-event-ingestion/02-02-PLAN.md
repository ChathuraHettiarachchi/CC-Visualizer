<objective>
## Goal
Wire the SSE pipeline into the browser UI: a React hook consumes `/api/events`, derives live sessions, and drives the SessionTabs bar. Header shows real connection status. A JSONL replay endpoint lets users load past sessions without Claude Code running.

## Purpose
Phase 2 is only useful when the UI actually reacts to Claude Code events. This plan closes the loop between the server-side event pipeline (02-01) and the visible UI — making sessions appear as Claude Code runs.

## Output
- `hooks/useSSE.ts` — EventSource hook returning `{ sessions, connected }`
- `app/page.tsx` — wired to real sessions from useSSE
- `components/layout/Header.tsx` — live connection status dot (green/amber/grey)
- `app/api/replay/route.ts` — POST endpoint to replay JSONL log files
</objective>

Add to ~/.claude/settings.json under "hooks":
```json

"PostToolUse": [{"matcher":"","hooks":[{"type":"http","url":"http://localhost:3000/api/hooks","timeout":5,"async":true}]}],
"Notification": [{"matcher":"","hooks":[{"type":"http","url":"http://localhost:3000/api/hooks","timeout":5,"async":true}]}],
"Stop": [{"matcher":"","hooks":[{"type":"http","url":"http://localhost:3000/api/hooks","timeout":5,"async":true}]}]
```
`async: true` ensures hooks never block Claude Code execution.

<task type="auto">
  <name>Task 1: Create useSSE hook — EventSource → sessions</name>
  <files>hooks/useSSE.ts</files>
  <action>
    Create `hooks/useSSE.ts` (client-only hook):
    - `"use client"` is NOT needed on a hook file — just mark it as using client APIs internally
    - Import `useState`, `useEffect` from react
    - Import `ClaudeEvent` from `@/lib/types`

    Export interface `SessionInfo { id: string; label: string; lastSeen: number }`

    Export `function useSSE()`:
    - State: `sessionMap = useRef(new Map<string, SessionInfo>())` — ref to avoid stale closure
    - State: `sessions: SessionInfo[]` — derived array for renders
    - State: `connected: boolean`
    - useEffect (runs once on mount):
      - `const es = new EventSource('/api/events')`
      - `es.onopen = () => setConnected(true)`
      - `es.onerror = () => setConnected(false)`
      - `es.onmessage = (e) => { ... }`:
        - Parse: `const event: ClaudeEvent = JSON.parse(e.data)`
        - If `sessionMap.current` does NOT have `event.session_id`:
          - Assign label: `Session ${sessionMap.current.size + 1}`
          - Add to map: `sessionMap.current.set(id, { id, label, lastSeen: event.timestamp })`
        - Else: update `lastSeen`
        - Update state: `setSessions(Array.from(sessionMap.current.values()))`
      - Cleanup: `return () => es.close()`
    - Return `{ sessions, connected }`

    Avoid: Do NOT import this hook in server components — only use in client components.
    Avoid: Do NOT use useState for sessionMap — use useRef to avoid re-renders on every event.
  </action>

<task type="auto">
  <name>Task 3: JSONL replay endpoint</name>
  <files>app/api/replay/route.ts</files>
  <action>
    Create `app/api/replay/route.ts`:
    - Add `export const runtime = 'nodejs'` at top
    - Import `readFileSync` from 'fs'
    - Import `pushEvent` from `@/lib/event-store`
    - Import `ClaudeEvent` from `@/lib/types`

    Export `POST(request: Request)`:
    - Parse body: `{ filePath }`
    - Validate: filePath must be a non-empty string → 400 if missing
    - Read file with `readFileSync(filePath, 'utf-8')` — wrapped in try/catch → 400 if unreadable
    - Split by newline, filter empty lines
    - For each line:
      - Try `JSON.parse(line)`
      - If result has `session_id` (string) and `hook_event_name` (string):
        - Add timestamp if missing: `if (!parsed.timestamp) parsed.timestamp = Date.now()`
        - Call `pushEvent(parsed as ClaudeEvent)`
        - Increment counter
      - Catch: skip invalid JSON lines silently
    - Return `Response.json({ ok: true, pushed: N })`

    Avoid: Do NOT add path validation/restrictions — this is a local-only dev tool.
  </action>

    ```bash
      -H "Content-Type: application/json" \
      -d '{"filePath":"/tmp/test.jsonl"}' | grep '"pushed":1'
    ```
  </verify>
