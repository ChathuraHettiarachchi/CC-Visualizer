<objective>
## Goal
Fix the jarring fitView-on-every-event camera reset and add visual node selection: the camera only re-fits when the active session changes or on first load, and clicking a node highlights it with an accent border while lifting the selected node ID to page.tsx for Phase 4.

## Purpose
03-01 left two UX problems: (1) the `fitView` prop resets the camera position on every new event, making the graph unusable during live sessions; (2) nodes aren't visually selectable, blocking Phase 4's click-to-inspect panels. This plan fixes both before handing off to Phase 4.

## Output
- `components/canvas/GraphCanvas.tsx` — imperative fitView via `useReactFlow`, `sessionId` prop, `onNodeSelect` prop
- `components/graph/ToolCallNode.tsx` — border highlights on `selected`
- `components/graph/NotificationNode.tsx` — border highlights on `selected`
- `components/graph/StopNode.tsx` — border highlights on `selected`
- `app/page.tsx` — passes `sessionId` + `onNodeSelect` to GraphCanvas, stores `selectedNodeId` state
</objective>

<task type="auto">
  <name>Task 1: Imperative fitView — stable camera during live updates</name>
  <files>components/canvas/GraphCanvas.tsx, app/page.tsx</files>
  <action>
    **Update `components/canvas/GraphCanvas.tsx`:**

    Add `sessionId: string` and `onNodeSelect?: (nodeId: string) => void` props to both `GraphCanvasProps` and `FlowCanvasProps`.

    Inside `FlowCanvas`:
    - Import `useReactFlow`, `useRef` from their packages
    - Add: `const { fitView } = useReactFlow()`
    - Add refs: `const prevSessionId = useRef<string>("")` and `const hasFitted = useRef(false)`
    - Remove `fitView` prop from `<ReactFlow>`
    - Add `onNodeClick={(_, node) => onNodeSelect?.(node.id)}` to `<ReactFlow>`
    - Add useEffect for imperative fit:
      ```ts
      useEffect(() => {
        if (nodes.length === 0) {
          hasFitted.current = false;
          return;
        }
        const sessionChanged = sessionId !== prevSessionId.current;
        const firstNodes = !hasFitted.current;
        if (sessionChanged || firstNodes) {
          prevSessionId.current = sessionId;
          hasFitted.current = true;
          const t = setTimeout(() => fitView({ duration: 300, padding: 0.2 }), 50);
          return () => clearTimeout(t);
        }
      }, [nodes.length, sessionId, fitView]);
      ```
      This fires when node count changes or session changes, but only re-fits when truly needed.

    Pass `sessionId` and `onNodeSelect` from `GraphCanvas` down to `FlowCanvas`.

    **Update `app/page.tsx`:**
    - Add state: `const [selectedNodeId, setSelectedNodeId] = useState<string | null>(null)`
    - Reset selection on session change:
      ```ts
      useEffect(() => { setSelectedNodeId(null); }, [activeId]);
      ```
    - Pass to GraphCanvas: `<GraphCanvas events={...} sessionId={activeId} onNodeSelect={setSelectedNodeId} />`

    Avoid: Do NOT call `fitView` synchronously — React Flow nodes aren't in the DOM yet at the time of render. Always use setTimeout with a small delay (50ms is sufficient).
    Avoid: Do NOT use `nodes` as a dependency for the fitView effect — use `nodes.length` to avoid referential inequality triggering extra fits.
  </action>
  <verify>
    `npm run build` passes. Manual test: replay events → camera fits to show nodes. Pan/zoom manually, then replay more events → camera does NOT reset. Switch session tab → camera fits new session.
  </verify>
  <done>AC-1, AC-2, AC-3 satisfied: camera stable during live updates, fits on session change and first load</done>
