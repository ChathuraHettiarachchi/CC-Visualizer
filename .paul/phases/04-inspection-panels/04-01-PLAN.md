<objective>
## Goal
Add a 320px right-side inspector panel that opens when a graph node is clicked: the top half shows node-specific detail (tool name, full input/output JSON, or notification message), the bottom half shows a scrollable session timeline that highlights the selected event.

## Purpose
Nodes are selectable since Phase 3 but clicking reveals nothing. Phase 4 closes that gap — the inspector panel is the primary debugging surface, letting users drill into what Claude Code actually did at each step.

## Output
- `components/canvas/GraphCanvas.tsx` — onNodeSelect upgraded to pass `{ id, type, data }` instead of just `id`
- `app/page.tsx` — `selectedNode` state (replaces `selectedNodeId`); layout updated to flex-row with panel
- `components/panels/InspectorPanel.tsx` — 320px right sidebar with header, close button, scrollable body
- `components/panels/NodeDetail.tsx` — node-type-specific content (ToolCall / Notification / Stop)
- `components/panels/Timeline.tsx` — chronological event list, selected event highlighted
</objective>

    **Create `components/panels/Timeline.tsx`:**

    Props:
    ```ts
    interface TimelineProps {
      events: ClaudeEvent[];
      selectedNode: { id: string; type: string | undefined; data: Record<string, unknown> };
    }
    ```

    Logic — determine if an event is the "selected" one:
    ```ts
    function isSelected(event: ClaudeEvent, selectedNode: SelectedNode): boolean {
      if (selectedNode.type === 'toolcall') {
        const toolUseId = selectedNode.id.slice(5); // strip 'tool-' prefix
        return ('tool_use_id' in event) && event.tool_use_id === toolUseId;
      }
      return event.timestamp === (selectedNode.data.timestamp as number);
    }
    ```

    Render sorted events as a list:
    ```tsx
    const sorted = [...events].sort((a, b) => a.timestamp - b.timestamp);

    return (
      <div style={{ flex: 1, overflowY: 'auto', fontFamily: 'monospace', fontSize: 11 }}>
        <div style={{ padding: '8px 16px 4px', fontSize: 10, fontWeight: 700, color: '#8b949e', textTransform: 'uppercase', letterSpacing: 1 }}>
          Timeline
        </div>
        {sorted.map((event, i) => {
          const selected = isSelected(event, selectedNode);
          return (
            <div key={i} style={{
              padding: '6px 16px',
              display: 'flex', gap: 10, alignItems: 'flex-start',
              background: selected ? 'rgba(31,111,235,0.1)' : 'transparent',
              borderLeft: selected ? '2px solid #1f6feb' : '2px solid transparent',
            }}>
              <span style={{ color: '#8b949e', flexShrink: 0 }}>
                {new Date(event.timestamp).toLocaleTimeString()}
              </span>
              <span style={{ color: eventColor(event), flexShrink: 0 }}>
                {eventLabel(event)}
              </span>
            </div>
          );
        })}
      </div>
    );
    ```

    Helper functions (inline, not exported):
    - `eventLabel(event)`: PreToolUse → `⬆ ${event.tool_name}`, PostToolUse → `⬇ ${event.tool_name}`, Notification → `💬 notification`, Stop/SubagentStop → `■ stop`
    - `eventColor(event)`: PreToolUse → `#1f6feb`, PostToolUse → `#3fb950`, Notification → `#d29922`, Stop/SubagentStop → `#8b949e`

    Avoid: Do NOT import ClaudeEvent union in a way that causes type errors — use `'tool_use_id' in event` for narrowing.
    Avoid: Do NOT use emoji as sole identifiers — keep the text label too (accessibility).
