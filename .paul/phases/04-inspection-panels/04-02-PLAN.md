<objective>
## Goal
Add a file attention heatmap panel showing which files were touched most during the active session, ranked by tool call count with a visual heat bar.

## Purpose
Closes out Phase 4 / v0.1 — developers get a session-level view of file activity alongside the node-level inspector. Answers "what did the agent focus on?" at a glance.

## Output
- `components/panels/HeatmapPanel.tsx` — new standalone panel component
- `app/page.tsx` — right panel shows HeatmapPanel by default; InspectorPanel on node select
</objective>

<acceptance_criteria>

## AC-1: Heatmap lists files ranked by touch count
```gherkin
Given a session with PreToolUse events for file-touching tools (Read, Write, Edit, MultiEdit, NotebookEdit)
When the right panel renders
Then files are listed in descending order of touch count with a heat bar whose width is proportional to count/max
```

## AC-2: Correct tools and file path keys extracted
```gherkin
Given PreToolUse events in a session
When computing the file list
Then only Read/Write/Edit/MultiEdit/NotebookEdit tool names are counted
  And Read/Write/Edit/MultiEdit use tool_input.file_path
  And NotebookEdit uses tool_input.notebook_path
  And tools with no extractable file path (Bash, Grep, Glob) are ignored
```

## AC-3: HeatmapPanel shown as default right panel
```gherkin
Given an active session with events
When no node is selected
Then a 320px right panel shows the file heatmap (same styling as InspectorPanel)
```

## AC-4: Inspector takes over on node select; heatmap returns on close
```gherkin
Given the HeatmapPanel is showing
When the user clicks a graph node
Then InspectorPanel replaces HeatmapPanel (existing 04-01 behavior unchanged)
  And when the user closes the inspector, HeatmapPanel reappears
```

## AC-5: Empty state when no file events
```gherkin
Given a session with no file-touching tool calls (or no session active)
When the HeatmapPanel renders
Then a "No file activity yet" message is shown instead of an empty list
```

<task type="auto">
  <name>Task 1: Build HeatmapPanel component</name>
  <files>components/panels/HeatmapPanel.tsx</files>
  <action>
    Create `components/panels/HeatmapPanel.tsx`.

    **Props:** `{ events: ClaudeEvent[] }`

    **File extraction logic:**
    - Filter to `PreToolUse` events only
    - Map tool names to their file path key:
      ```
      Read        → tool_input.file_path
      Write       → tool_input.file_path
      Edit        → tool_input.file_path
      MultiEdit   → tool_input.file_path
      NotebookEdit → tool_input.notebook_path
      ```
    - Skip all other tool names
    - Cast the extracted value as `string | undefined`; skip if falsy
    - Count occurrences: `Map<string, number>` keyed by full file path
    - Sort entries descending by count

    **Rendering:**
    - Use same panel shell as InspectorPanel: 320px, `#161b22` bg, left border `1px solid #30363d`
    - Sticky header (same as Timeline header style): uppercase label "Files", monospace, 10px, `#8b949e`
    - For each file entry:
      - Row: filename (basename, `#e6edf3`, 12px mono) + count badge (`#8b949e`, 10px)
      - Dimmed dir path below filename (`#8b949e`, 10px, truncated with ellipsis)
      - Heat bar: full-width track (`#21262d`), filled portion width = `(count/maxCount * 100)%`, color `#1f6feb` at opacity 0.6
    - Empty state: centered text "No file activity yet" in `#8b949e`, 12px mono

    **Use inline styles throughout** — consistent with existing panel components (no Tailwind classes).

    Avoid: extracting `path` from Grep/Glob (those are directory patterns, not specific files).
  </action>

  </verify>
