<objective>
## Goal
Add node search/filter (dim non-matching nodes) and replay speed control (0.5×–4× multiplier) to the 3D canvas.

## Purpose
Large sessions can have 50+ nodes making it hard to find a specific tool call. Search lets users highlight by tool name. Speed control lets users skim long replays quickly.

## Output
- Search input overlay on canvas; non-matching nodes render at 10% opacity
- Speed selector buttons (0.5×, 1×, 2×, 4×) in the existing playback bar
</objective>

<acceptance_criteria>

## AC-1: Node Search Filters Visible Nodes
```gherkin
Given the canvas has nodes rendered
When the user types a tool name (e.g. "Bash") in the search input
Then nodes whose label contains that string stay fully opaque
And all other nodes dim to ~10% opacity
And clearing the search restores full opacity to all nodes
```

## AC-2: Search Input Is Overlaid On Canvas
```gherkin
Given the canvas is visible
When the user looks at the top-left area
Then a small search input (glass style) is visible at all times
And it does not obstruct node interaction
```

## AC-3: Replay Speed Adjusts Cadence
```gherkin
Given the replay is active (playback bar visible)
When the user selects "2×"
Then each node is visited for ~1100ms (2200ms / 2)
And the speed persists until changed or playback stops
```

  <name>Task 1: Search input overlay + node dimming</name>
  <files>components/canvas/GraphCanvas.tsx</files>
  <action>
    Add `const [searchQuery, setSearchQuery] = useState("")` to GraphCanvas.

    Add a mounted-gated search input div positioned absolute top-left (12px, 12px) with glass styling:
    - width: 200px, font: IBM Plex Mono 12px
    - placeholder: "Search nodes…"
    - onChange: `setSearchQuery(e.target.value)`
    - Only render when `mounted` is true (same pattern as playback controls)

    In the ForceGraph3D `nodeOpacity` prop (currently fixed at 0.92), change to a function:
    ```
    nodeOpacity={(node) => {
      if (!searchQuery) return 0.92;
      if (node.type === "__session_label") return 0;
      const label = node.type === "toolcall"
        ? (node.data?.toolName ?? "tool")
        : node.type;
      return label.toLowerCase().includes(searchQuery.toLowerCase()) ? 0.92 : 0.08;
    }}
    ```

    Avoid: changing `nodeColor` for search (opacity is the right lever — color stays informative).
    Avoid: making the search input focusable via Tab before the canvas (add tabIndex={-1} or keep natural order).
  </action>
  <verify>npx tsc --noEmit passes. Open app, type "Bash" — non-Bash nodes dim visibly. Clear input → all nodes return to full opacity.</verify>

    {[0.5, 1, 2, 4].map(s => (

      </button>

    Avoid: resetting replaySpeed when playback stops — preserve last used speed for next replay.
