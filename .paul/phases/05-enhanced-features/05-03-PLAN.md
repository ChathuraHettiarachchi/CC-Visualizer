<objective>
## Goal
Two insight features: (1) tool call duration heatmap — color nodes by how long each tool took (Pre→Post delta), toggled via a canvas button; (2) subagent tree — LeftRail session list shows parent→child hierarchy instead of a flat list.

## Purpose
Duration heatmap lets developers instantly spot slow tool calls (red = slow, green = fast) without reading timestamps. Subagent tree makes the agent hierarchy visible — currently `subagentCount` is tracked but not shown as a tree.

## Output
- `eventsToGraph` stores `duration` (ms) in toolcall node data
- Toggle button on canvas switches between type-color mode and heatmap mode
- `useSSE` exports `childSessions: Map<string, string[]>` (parentId → childIds)
- LeftRail renders tree rows with indented child sessions
</objective>

    Add a heatmap color helper function above the component:
    ```ts
    function durationColor(duration: number | null, minMs: number, maxMs: number): string {
      if (duration === null) return TYPE_COLOR.toolcall;
      if (maxMs === minMs) return "#22c55e";
      const t = (duration - minMs) / (maxMs - minMs); // 0=fast, 1=slow
      // Interpolate green (#22c55e) → amber (#ffbf69) → red (#f87171)
      if (t < 0.5) {
        const u = t * 2;
        return `rgb(${Math.round(34 + u*(255-34))}, ${Math.round(197 + u*(191-197))}, ${Math.round(94 + u*(105-94))})`;
      } else {
        const u = (t - 0.5) * 2;
        return `rgb(${Math.round(255 + u*(248-255))}, ${Math.round(191 + u*(113-191))}, ${Math.round(105 + u*(113-105))})`;
      }
    }
    ```

    Compute `minDuration`/`maxDuration` inside the `nodeColor` callback lazily via useMemo:
    ```ts
    const durationRange = useMemo(() => {
      const durations = graphData.nodes
        .map(n => (n as any).data?.duration as number | null)
        .filter((d): d is number => d !== null);
      return { min: Math.min(...durations), max: Math.max(...durations) };
    }, [graphData.nodes]);
    ```

    Update `nodeColor` prop:
    ```ts
    nodeColor={(node) => {
      if (node.isStart) return START_COLOR;
      if (heatmapMode && node.type === "toolcall") {

      }
      return node.sessionColor ?? TYPE_COLOR[node.type] ?? "#61d0ff";
    }}
    ```
