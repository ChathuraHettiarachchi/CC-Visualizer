<objective>
## Goal
Add a collapsible live event feed: a real-time scrolling log at the bottom of the canvas showing events as they arrive, color-coded by type.

## Purpose
The 3D graph shows structure but not raw event data as it streams in. The event feed gives developers a terminal-like view of exactly what Claude Code is doing right now, without clicking individual nodes.

## Output
- New `components/panels/EventFeed.tsx` component
- Collapsible drawer at the bottom of the center canvas column in `app/page.tsx`
- Auto-scrolls to latest event; color-coded by event type
</objective>

<acceptance_criteria>

## AC-1: Feed Shows Incoming Events In Real Time
```gherkin
Given the app has an active session
When a new event arrives via SSE
Then a new row appears at the bottom of the feed within 100ms
And it shows: timestamp (HH:MM:SS), event type badge, tool name or message excerpt
```

## AC-2: Feed Is Color-Coded By Event Type
```gherkin
Given events of different types are in the feed
When the user views the feed
Then PreToolUse rows have accent blue (#61d0ff) type badge
And PostToolUse rows have accent green (#7cf3c8) type badge
And Notification rows have amber (#ffbf69) type badge
And Stop/SubagentStop rows have muted color (#91a8c7) type badge
```

## AC-3: Feed Is Collapsible
```gherkin
Given the feed is visible
When the user clicks the "▾ Feed" toggle button
Then the feed collapses to show only the toggle button (height ~32px)
And clicking again expands it to ~180px height
And collapsed state persists while navigating between sessions
```

## AC-4: Feed Auto-Scrolls And Caps At 200 Rows
```gherkin
Given the feed has received 200+ events
When a new event arrives
Then the oldest events are dropped (keep last 200)
And the feed stays scrolled to the bottom unless user has scrolled up
```

    - Timestamp: `new Date(event.timestamp).toLocaleTimeString("en-GB")` in `color: var(--muted)`

      - PostToolUse → `#7cf3c8`
      - Notification → `#ffbf69`
      - Stop/SubagentStop → `#91a8c7`

    Auto-scroll: use a `bottomRef = useRef<HTMLDivElement>(null)` at the bottom of the list.    
    ```
    <div style={{ borderTop: "1px solid var(--line)", background: "rgba(7,17,31,0.9)" }}>
      <button onClick={toggle} style={...}>▾ Feed ({events.length})</button>
      {!collapsed && (
        <div ref={scrollRef} style={{ height: 180, overflowY: "auto", padding: "6px 12px" }}>
          {last200.map((e, i) => <Row key={i} event={e} />)}
          <div ref={bottomRef} />
        </div>
      )}
    </div>
    ```
