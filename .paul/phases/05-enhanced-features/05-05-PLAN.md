<objective>
## Goal
Node detail diff: shift-click a second node while one is already selected to compare both side by side in the right rail — showing their type, tool name, input, output, and duration with differences highlighted.

## Purpose
Developers often want to compare two similar tool calls ("why did Bash take 3s here but 0.2s there?") or compare a PreToolUse input against a different call's output. The diff view surfaces these comparisons without manual inspection.

## Output
- `app/page.tsx` manages `selectedNode` (first) and `compareNode` (second) state
- `GraphCanvas` fires `onSecondNodeSelect` on shift+click when a first node is already selected
- `components/panels/DiffPanel.tsx` renders side-by-side comparison
- RightRail shows DiffPanel when two nodes are selected; shows normal inspector when one is selected
</objective>

  <action>
    **GraphCanvas.tsx:**
    Add `onSecondNodeSelect?: (node: SelectedNode | null) => void` to `GraphCanvasProps`.

    In `handleNodeClick`, the callback currently receives a node object from react-force-graph-3d. The raw click event is NOT passed as a second argument by ForceGraph3D's `onNodeClick`. Instead, use `onNodeClick` which receives `(node, event)` — the second argument is the native MouseEvent.

    Update `onNodeClick` signature to accept the event:
    ```tsx
    onNodeClick={(node: Record<string, unknown>, event: MouseEvent) => {
      if (node.type === "__session_label") return;
      setPlaybackIdx(null);
      const selected: SelectedNode = {
        id:   node.id as string,
        type: node.type as string | undefined,
        data: (node.data as Record<string, unknown>) ?? {},
      };
      if (event.shiftKey && onSecondNodeSelect) {
        onSecondNodeSelect(selected);
      } else {
        onNodeSelect?.(selected);
        onSecondNodeSelect?.(null); // clear compare on normal click
      }
    }}
    ```
    Remove the separate `handleNodeClick` useCallback and inline this logic directly in the JSX prop (or keep as callback — either is fine but update the signature).

    **app/page.tsx:**
    Add `const [compareNode, setCompareNode] = useState<SelectedNode | null>(null)`.
    Clear compareNode when session changes: add `setCompareNode(null)` to the `useEffect([activeId])`.
    Pass `onSecondNodeSelect={setCompareNode}` to `<GraphCanvas>`.
    Pass `compareNode={compareNode}` and `onClearCompare={() => setCompareNode(null)}` to `<RightRail>`.

    Avoid: storing shiftKey state in a ref — read directly from the event object.
    Avoid: allowing the same node to be both selectedNode and compareNode (check `node.id !== selectedNode?.id` before setting compareNode).

    **components/panels/DiffPanel.tsx** (new file):
    Props: `{ nodeA: SelectedNode; nodeB: SelectedNode; onClear: () => void }`

    Extract comparison fields from each node's data:
    ```ts
    function fields(node: SelectedNode) {
      const d = node.data;
      return {
        type:     node.type ?? "—",
        tool:     (d.toolName as string) ?? "—",
        input:    d.toolInput ? JSON.stringify(d.toolInput, null, 2) : "—",
        output:   d.toolResponse ? JSON.stringify(d.toolResponse, null, 2).slice(0, 400) : "—",
        duration: d.duration != null ? `${d.duration}ms` : "—",
        status:   (d.status as string) ?? "—",
      };
    }
    ```

    Render a 3-column grid: label | nodeA value | nodeB value.
    Rows: Type, Tool, Status, Duration, Input, Output.

    For each row, compare `valA === valB`. If different, apply `background: rgba(255,191,105,0.08)` tint to the row.
    For Input and Output (multiline), show in a `<pre>` with `max-height: 120px, overflow-y: auto`.

    Header: `[node A label] vs [node B label]` with a `✕ Clear compare` button that calls `onClear`.

    Layout:
    ```
    <div style={{ overflow: "auto", fontSize: 12, fontFamily: IBM Plex Mono }}>
      <div style={{ display: "flex", justifyContent: "space-between", marginBottom: 8 }}>
        <span style={{ color: "#61d0ff" }}>{nodeA.id.slice(0,12)}…</span>
        <button onClick={onClear} style={{ ... }}>✕ Clear compare</button>
        <span style={{ color: "#ffbf69" }}>{nodeB.id.slice(0,12)}…</span>
      </div>
      {rows.map(({ label, valA, valB }) => (
        <div key={label} style={{
          display: "grid", gridTemplateColumns: "80px 1fr 1fr", gap: 6,
          padding: "4px 0",
          background: valA !== valB ? "rgba(255,191,105,0.08)" : "transparent",
          borderBottom: "1px solid rgba(255,255,255,0.04)",
        }}>
          <span style={{ color: "var(--muted)", fontSize: 10 }}>{label}</span>
          <ValueCell value={valA} highlight={valA !== valB} color="#61d0ff" />
          <ValueCell value={valB} highlight={valA !== valB} color="#ffbf69" />
        </div>
      ))}
    </div>
    ```
