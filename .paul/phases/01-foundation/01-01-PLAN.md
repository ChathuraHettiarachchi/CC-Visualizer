<objective>
## Goal
Scaffold a Next.js 14 project with TypeScript, Tailwind CSS, and React Flow (@xyflow/react) installed. Create a working shell: header bar, multi-session tab switcher, and an empty interactive canvas powered by React Flow.

## Purpose
Establishes the foundation every subsequent phase builds on. Without a running app and React Flow wired up, no graph rendering or event streaming can be built.

## Output
- Running Next.js dev server (`pnpm dev`) showing the cc-visualizer shell
- React Flow canvas renders (empty) with pan/zoom working
- Session tab bar renders with a placeholder "Session 1" tab
</objective>
